MIRI-CLI-008 — JSON everywhere

Every command supports JSON output

must severity HIGH · 4 weight 4 CLI Spec §2.5

Definition: standards/cli/checks/MIRI-CLI-008.yaml · view · raw

Violation
$ tool status --json error: unknown flag: --json $ tool status NAME STATE UPTIME api running 4d # only a human table; agents must scrape it
Compliant
$ tool status --json {"schema_version": "1", "services": [ {"name": "api", "state": "running", "uptime_seconds": 350400}]} $ tool status --json | jq -e .services[0].state "running"

Why this matters

The stability contract (landscape §3.4) explicitly excludes human-readable text and its wording from SemVer coverage — so a command without JSON output forces agents to scrape prose the vendor is free to reword at any time, making every copy-edit a de-facto breaking change that ships without a version bump. This is the mechanism behind a decade of screen-scraping breakage that pushed docker, kubectl, and gh to grow structured-output flags command by command; CLI Spec §2.5 closes the gap by making JSON-on-stdout the defined machine channel for every command, not a per-command afterthought.

Definition

Agents parse stdout; anything unstructured, inconsistent, or polluted forces guesswork and burns recovery turns. This check verifies: Every command supports JSON output.

When it fires

  • Any command enumerated in --describe lacks the JSON output mode
  • The standard output flag is rejected (unknown flag) on some commands
  • A command's JSON mode emits output that a strict JSON parser rejects

How to fix it

Support the JSON output flag on every command.

  1. Derive JSON output from the same data structures that feed the human formatter — one struct, two renderers (CLI Spec §2.3) — rather than retrofitting per command
  2. Register the output flag once at the root parser so new subcommands inherit it (see MIRI-CLI-009)
  3. Add a CI loop: for every command in --describe, run it with the JSON flag and pipe stdout through jq -e . (or python3 -m json.tool) to assert a parseable document
