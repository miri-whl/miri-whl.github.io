Why this matters

Honest degradation is the property that makes the whole bare/miri comparison mean anything: if a consumer answers the same way whether or not the metadata exists, the metadata is not what produced the answer. The Discovery Contract calls the absent-versus-failed split 'the single most consequential clause in this document' precisely because a consumer's honesty is only checkable if absence is reported. No existing tool checks this because no existing tool defines a consumer.

Definition

A consumer driven against a package that ships no such document must report the absence. This check verifies that the consumer's output states the document is absent rather than omitting the fact or filling the gap.

When it fires

  • The consumer is driven against the bare fixture and its output does not state that the requested document is absent
  • The consumer reports an absent document as an error, or an error as an absence
  • The consumer silently omits any mention of a document it was asked about and did not receive

How to fix it

Branch on the envelope's present field and emit an explicit 'no such document' statement in the consumer's output

  1. Branch on the envelope's present field and emit an explicit 'no such document' statement in the consumer's output
  2. Distinguish absence from failure in the output vocabulary, mirroring the ok/present split
