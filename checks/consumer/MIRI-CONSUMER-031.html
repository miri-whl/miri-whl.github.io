MIRI-CONSUMER-031 — Applies the SSRF guard to any URL it resolves from metadata

Applies the SSRF guard to any URL it resolves from metadata

must severity CRITICAL · 5 weight 8 Lifecycle and Security Metadata §9.2Discovery Contract §9.2

Definition: standards/consumption/checks/MIRI-CONSUMER-031.yaml · view · raw

Violation
GET http://169.254.169.254/latest/meta-data/ (from update_check.url)
Compliant
The package's update_check URL resolves to a link-local address (169.254.169.254). Blocked by the SSRF guard; not fetched.

Why this matters

The adversarial fixture points update_check at the cloud metadata address. A consumer that fetches it without the guard turns publisher-controlled data into a server-side request against its own infrastructure, and may return credentials to the caller. Because the contract deliberately makes the surface fetch nothing, this obligation has nowhere else to live.

Definition

The surface fetches nothing, so resolving a declared URL is the consumer's act. This check verifies the consumer applies the SSRF guard when it does so.

When it fires

  • The consumer fetches a metadata-supplied URL over plain HTTP, or one resolving to a private, link-local, or cloud-metadata address
  • The consumer follows a redirect without re-validating the destination
  • The consumer forwards credentials to a metadata-supplied endpoint
  • The consumer emits a publisher URL to a browser tool, a fetch capability, a subordinate agent, or a user-facing link without applying the guard first, or without emitting it inert. Arranging for something else to make the request is the same exposure with the audit trail removed, so the emission arm is scored by this check and not left to the resolution arm alone

How to fix it

Apply the §9.2 guard before every fetch: HTTPS only, block private and link-local ranges, re-validate after redirects

  1. Apply the §9.2 guard before every fetch: HTTPS only, block private and link-local ranges, re-validate after redirects
  2. Never attach the consumer's credentials to a publisher-declared endpoint
