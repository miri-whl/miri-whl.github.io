MIRI-PY-016 — Example index coherent

AGENT_EXAMPLES.json entries ↔ files on disk, both directions

must severity MINOR · 2 weight 2 Miri Wheel Ext. §4.1

Definition: standards/python/checks/MIRI-PY-016.yaml · view · raw

Violation
AGENT_EXAMPLES.json: "authentication": {"file": "examples/auth.py", ...} <- wheel ships examples/authentication.py, not auth.py On disk but unindexed: examples/error_handling.py <- exists, invisible to any agent reading the index
Compliant
AGENT_EXAMPLES.json examples map <-> examples/ on disk, one-to-one: "quickstart": {"file": "examples/quickstart.py"} -> exists "authentication": {"file": "examples/authentication.py"} -> exists ls examples/: __init__.py quickstart.py authentication.py (nothing unindexed; all path ids referenced by learning_paths exist)

Why this matters

AGENT_EXAMPLES.json (Miri Wheel Extensions §4.1) is how agents discover examples without directory-walking; the index, not the filesystem, is the contract surface. An entry pointing at a missing file sends every consumer to a dead path at machine speed, while an on-disk example with no entry is invisible however good it is. Because the index is build-generated, a mismatch in either direction is deterministic evidence of a broken generation pipeline rather than a content judgment call.

Definition

Embedded examples are the primary learning path for agents; an example that does not run teaches a wrong lesson at machine speed. This check verifies: AGENT_EXAMPLES.json entries ↔ files on disk, both directions.

When it fires

  • an examples[*].file path in AGENT_EXAMPLES.json does not exist in the wheel
  • a *.py file under examples/ (excluding __init__.py) has no entry in the index
  • learning_paths, categories, prerequisites, or related reference an example id absent from the examples map

How to fix it

Regenerate the example index from the files on disk.

  1. Generate AGENT_EXAMPLES.json from a disk scan of examples/ at build time; never edit it by hand
  2. Fail the build on either direction of mismatch: indexed-but-missing file, or on-disk example with no entry
  3. Validate referential integrity during generation: every id named in learning_paths, categories, prerequisites, and related must exist in the examples map
