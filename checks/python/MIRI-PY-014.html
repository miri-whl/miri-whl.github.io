MIRI-PY-014 — Quickstart exists

examples/quickstart.py present

must severity MEDIUM · 3 weight 3 Miri Wheel Ext. §5.1

Definition: standards/python/checks/MIRI-PY-014.yaml · view · raw

Violation
Wheel contents: example_sdk/agent-metadata/sdk-manifest.json example_sdk/examples/advanced.py METADATA: Agent-Quickstart-File: examples/quickstart.py <- points at a file the wheel does not contain
Compliant
example_sdk/examples/quickstart.py: from example_sdk import Client client = Client(api_key="YOUR_API_KEY") # placeholder documented in header result = client.fetch("users") print(f"fetched {len(result)} records") # end-to-end in four lines, no extra dependencies

Why this matters

Miri Wheel Extensions §5.1 names examples/quickstart.py as the one required example and §9.1.1 makes its presence the floor of basic conformance; the enhanced METADATA field Agent-Quickstart-File points to it by path. It is the first artifact an agent executes to confirm its model of the API before generating integration code — in its absence the agent synthesizes the install-to-first-result path from prose and signatures, which is exactly the guessing this standard exists to remove.

Definition

Embedded examples are the primary learning path for agents; an example that does not run teaches a wrong lesson at machine speed. This check verifies: examples/quickstart.py present.

When it fires

  • examples/quickstart.py is absent from the built wheel
  • METADATA Agent-Quickstart-File names a path that does not exist in the wheel
  • quickstart.py exists but never imports the package it ships in, or contains no executable statements (empty stub)

How to fix it

Add a minimal runnable quickstart example.

  1. Add examples/quickstart.py demonstrating the minimal install-to-first-result flow: import, configure, one call, printed result
  2. Keep it dependency-light — nothing beyond the package's own Requires-Dist; move auth, error, and async flows to authentication.py, error_handling.py, and async/ per §5.1
  3. Register it in AGENT_EXAMPLES.json with complexity "beginner" and set Agent-Quickstart-File: examples/quickstart.py in the enhanced METADATA
