MIRI-PY-038 — Templates coherent

TEMPLATES.json entries ↔ template files; placeholders documented

should severity LOW · 1 weight 2 Miri Wheel Ext. §4.4

Definition: standards/python/checks/MIRI-PY-038.yaml · view · raw

Violation
TEMPLATES.json: "basic_client": {"file": "templates/basic_client.py", "placeholders": {"API_KEY": {...}}} templates/basic_client.py: client = WeatherClient(api_key="API_KEY", region="REGION_CODE") # REGION_CODE undocumented — ships literally into consumer code; templates/async_client.py exists on disk but is unindexed
Compliant
TEMPLATES.json documents every token found in the template body: "placeholders": { "API_KEY": {"description": "Weather API key", "example": "wk_live_abc123", "required": true}, "REGION_CODE": {"description": "ISO region for the endpoint", "example": "us-east", "required": false}} # and every file under templates/ has exactly one index entry

Why this matters

Templates are copied verbatim into consumer projects, so their defects replicate: an index entry pointing at a file the wheel does not contain breaks scaffolding at the moment of use, and a token that appears in a template body but not in its placeholders map ships as a literal YOUR_API_KEY-style string into generated code — failing at runtime or getting committed as-is. The §4.4 schema exists so agents can substitute placeholders mechanically; every token the map omits is a substitution the agent cannot perform. Coherence is verified in both directions, like the example index (MIRI-PY-016).

Definition

Miri metadata must be discoverable at runtime and must never make the package worse for non-Miri consumers. This check verifies: TEMPLATES.json entries ↔ template files; placeholders documented.

When it fires

  • A templates.<id>.file path in TEMPLATES.json has no corresponding file in the installed package
  • A file under templates/ (other than __init__.py) has no TEMPLATES.json entry
  • A placeholder token occurring in a template body is absent from that entry's placeholders map, or a mapped placeholder lacks description or example

How to fix it

Regenerate the template index; document every placeholder.

  1. Generate TEMPLATES.json from the templates/ directory at build time rather than maintaining the index by hand
  2. Scan template bodies for placeholder tokens during the build and fail when any token is missing from the placeholders map
  3. Validate the index against the §4.4 structure in CI (entries ↔ template files, placeholders documented)
