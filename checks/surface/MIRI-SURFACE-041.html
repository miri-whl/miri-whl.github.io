MIRI-SURFACE-041 — Emits one row per import package; errors rather than picking among ambiguous one

Emits one row per import package; errors rather than picking among ambiguous ones

must severity MEDIUM · 3 weight 5 Discovery Contract

Definition: standards/consumption/checks/MIRI-SURFACE-041.yaml · view · raw

Violation
list() -> one row for a distribution providing two metadata-bearing packages
Compliant
{"schema_version": "1", "ok": false, "error": {"code": "AMBIGUOUS_PACKAGE", "retryable": false}}

Why this matters

One distribution can ship several top-level import packages, and a namespace package can split one import name across distributions. A surface that silently picks one answers confidently about a package the consumer did not ask about, and the consumer has no way to detect the substitution.

Definition

Surface obligation from the Discovery Contract. This check verifies: Emits one row per import package; errors rather than picking among ambiguous ones.

When it fires

  • list collapses several metadata-bearing import packages from one distribution into a single row
  • An import name provided by more than one installed distribution is resolved to one without an error

How to fix it

Emit one list row per import package, each with its own purl

  1. Emit one list row per import package, each with its own purl
  2. Return AMBIGUOUS_PACKAGE rather than choosing among candidates
