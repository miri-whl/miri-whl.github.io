Metadata surfaces — check definitions

Each requirement is verified by a check; each check failure instance is a violation. Conformance score = Σ weights of passing checks; any failing MUST caps the score at 74. Severity and violation units are canonical and feed the magnitude-aware health score. The YAML definitions are authoritative; the checklist table is the derived rendering.
